## Required Check

Before answering a current-state question, identify:

```text
1. Is this about current local/mule/helper state?
2. What proof object should prove it?
3. Is that proof object loaded/read here?
4. What kind of proof is it?
   - receipt
   - readback
   - commit/status block
   - helper report
   - mule return note
   - source extraction note
   - screenshot
   - user-pasted report
5. What trust level applies?
   - DIRECT_READ
   - USER_REPORTED
   - FILE_SEARCH_SURFACE
   - MAP_INFERENCE
   - MEMORY_ONLY
   - MISSING
6. Is the planned answer a state claim or orientation read?
7. If proof is missing, has missing proof been named as a finding?
```

## Legal Verdicts

```text
DIRECT STATE
Proof object loaded/read. State claim allowed.

USER-REPORTED STATE
User/mule/helper pasted a return, but receipt file is not independently loaded.

ORIENTATION ONLY
Support maps or route files are loaded, but current proof is absent.

MISSING PROOF FINDING
Needed proof object is absent or unnamed. This is the result.

CONFLICT
Map and receipt disagree. Local proof outranks map for current state.

STALE MAP WARNING
Map may still route, but cannot prove current state until refreshed.

BLOCKED
Cannot answer state without proof or explicit user choice to accept inference.
```

Hard stop:

```text
If proof object is absent, do not claim current state.
Say what proof is missing.
Name the next needed object.
```
