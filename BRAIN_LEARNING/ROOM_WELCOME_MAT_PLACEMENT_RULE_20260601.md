# Room Welcome Mat Placement Rule

Date: 2026-06-01
Status: BRAIN_LEARNING / PLACEMENT CANDIDATE / NOT DOCTRINE
SourceWork: ROOT_INTAKE_20260601

## Core Rule

All incoming files are welcome at the front door.

Not every file belongs in every room.

The house should receive material with a welcome mat, then route it by role, trust, risk, intimacy, and allowed use.

## Room Types

Public rooms:

- read-first indexes;
- source notes;
- custody receipts;
- research packs;
- safe snippets;
- manifests.

Working rooms:

- active build lanes;
- tool/script rooms;
- proof benches;
- current control surfaces.

Restricted rooms:

- authority surfaces;
- doctrine;
- ACTIVE_GUIDES;
- CURRENT_TRUTH_INDEX;
- private/personal source;
- executable tools;
- automation/watchers;
- bedroom-level material that needs explicit invitation.

## Placement Questions

Before moving or using an incoming file, ask:

1. What is it?
2. Who is allowed to read it?
3. Who is allowed to act on it?
4. Does it carry source, proof, tool power, private material, or live authority?
5. Is it a guest, resident, tool, receipt, source ore, parked idea, or blocked item?
6. What room makes its allowed use obvious?
7. What room would give it too much power?

## Bad Crossings

```text
WELCOME -> TRUSTED
ROOT_FILE -> ACTIVE_WORK
SOURCE_NOTE -> AUTHORITY
HELPER_SCRIPT -> TOOL
HANDOFF -> IMPLEMENTATION
MANIFEST -> PROOF
INVENTORY -> CLEANUP_PERMISSION
PUBLIC_ROOM -> BEDROOM
BEDROOM -> PUBLIC_ROOM
```

## Clean Placement Standard

A placed file should have:

- fitting room;
- reason;
- allowed use;
- forbidden use;
- source/custody pointer;
- return trigger if parked;
- receipt if moved;
- DoesNotProve;
- StopLine.

## DoesNotProve

This candidate proves only that the root intake used a welcome-mat placement pattern once. It does not authorize broad moving, deleting, private file exposure, doctrine promotion, or active-room admission.

## StopLine

When role, trust, privacy, authority, or execution risk is unclear, park in custody/review instead of moving into an active room.
