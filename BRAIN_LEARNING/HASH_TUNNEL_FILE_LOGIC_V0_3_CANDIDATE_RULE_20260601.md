## Route And Policy Grammar

Before a helper, packet, or worker moves through the house, name:

```text
FROM object
THROUGH relation
TO object
WITH proof need
UNDER authority scope
USING toolbelt
CARRYING output
LEAVING extra weight
RETURNING by path
STOPPING if condition
```

```text
May actor A perform operation O on object X under route R using proof P?
```
