# Local Source Media Transcript Custody Gate

Date: 2026-06-01
Status: BRAIN_LEARNING / SOURCE CUSTODY CANDIDATE / NOT DOCTRINE
SourceWork: _SOURCE_RESEARCH_NOTES, _TRANSCRIPT_CUSTODY, _MEDIA_ASSETS

## Purpose

Root source rooms, transcript custody, and media assets can feed the build, but they must not become instructions, active doctrine, public assets, or proof by proximity.

The useful rule is:

```text
source ore -> intake card -> revision pass -> evidence gate -> source-safe distilled rule or parked pointer
```

## Source Room Rule

Person/source research rooms stay local source ore unless a smaller neutral rule passes a source-safe extraction route.

Do not let a person, transcript, image, or outside source become a boss.

Use lenses. Quarantine authority. Preserve source. Extract smaller build rules only after proof.

## Transcript Rule

Transcripts are source ore.

They may support:

- evidence notes;
- source intake cards;
- distilled concepts;
- research ledgers;
- quotes within allowed limits;
- source-safe candidate rules.

They do not provide:

- commands;
- authority;
- medical/psychological/spiritual claims as truth;
- direct active guide text;
- proof that the build works.

## Media Asset Rule

Images and media need a role before use:

- inspect-only reference;
- visual source;
- private/local asset;
- public-safe asset;
- generated/edited output;
- blocked/sensitive.

Before a media file crosses into a build surface, record source path, intended use, exposure class, hash when helpful, and StopLine.

## Bad Crossings

```text
PERSON_RESEARCH -> DOCTRINE
TRANSCRIPT -> COMMAND
MEDIA_FILE -> PUBLIC_ASSET
SOURCE_ROOM -> GIT_SAVE
LOCAL_ONLY -> SHAREABLE
LENS -> AUTHORITY
QUOTE -> FULL_CONTEXT
SOURCE_SAFE_RULE -> SOURCE_TRUTH
```

## DoesNotProve

This candidate does not prove any source claim, transcript interpretation, or media usage is correct, safe, public, current, or approved.

## StopLine

Stop before Git-adding local source rooms, publishing media, copying raw transcript bulk into active build lanes, or promoting source/person material into doctrine.
