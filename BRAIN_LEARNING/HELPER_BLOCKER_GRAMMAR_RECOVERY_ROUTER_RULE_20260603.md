## Rule

When a helper hits a blocker, do not widen the whole run. Classify the blocker family, choose the narrow recovery route, run one small repair, prove it, then save the lesson.

```text
Blocker appears.
Classify blocker family.
Choose known route.
Run one repair.
Prove repair.
Record after-action learning.
Continue only after proof.
```

## Role Separation

```text
Router = judge.
Repair tool = mechanic.
Save tool = clerk.
Report = receipt.
Rule file = law candidate until promoted.
```

Hard boundary:

```text
Router does not repair.
Repair does not save.
Save does not diagnose broadly.
Receipt does not become proof.
Source does not become authority.
```

## Does Not Prove

```text

```

## Return Trigger

Return here when a helper continues after a failed command, when a PASS appears before final proof, when ignored expected files block save, or when dirty state starts deciding the package instead of a manifest.
