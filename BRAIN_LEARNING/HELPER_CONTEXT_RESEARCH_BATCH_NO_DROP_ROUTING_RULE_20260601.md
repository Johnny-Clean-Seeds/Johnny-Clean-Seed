# Helper Context Research Batch No Drop Routing Rule

Date: 2026-06-01
Status: BRAIN_LEARNING / RESEARCH ROUTING CANDIDATE / NOT DOCTRINE
SourceWork: HELPER_CONTEXT_AUTHORITY_PROOF_RESEARCH_PACK_20260531

## Purpose

The helper-context research pack carries a reusable no-drop research pattern:

```text
bigger research + clearer build knowledge + no silent drops + no false authority
```

Use it when a research packet grows across multiple domains and needs current read order without letting old versions disappear or become active authority.

## Routing Law

For each added research object:

1. Decide which batch/domain owns it.
2. Check whether the current batch is still reasonable.
3. Add to that batch if it fits.
4. Create a new batch if the file is too large or the topic is a new domain.
5. Add matrix rows for every new candidate object or important parked idea.
6. Mark each idea as `KEEP`, `ADD`, `PARK`, `SUPERSEDE_WITH_REASON`, or `WRONG_WITH_REASON`.
7. Never silently drop source material.

## Current Carry Method

Carry:

- current README/index;
- control rule when editing;
- active batch body;
- completed neighbors as pointers;
- matrix only when adding rows or checking coverage.

Drop from live carry:

- old run chatter;
- old summaries already embedded in files;
- full superseded bodies unless a no-drop audit needs them.

## Superseded Rule

Earlier files are not trash. Mark them:

```text
SUPERSEDED_BUT_PRESERVED
```

Load them for no-drop audits, proof checks, drift comparison, mistake recovery, or version-history questions.

## Parking Row Required Fields

```text
Idea / Source / Why parked / Return trigger / Neighbor batch / Risk if forgotten
```

## Bad Crossings

```text
LATEST_INDEX -> DOCTRINE
SOURCE_LOCK -> APPROVAL
OLDER_VERSION -> DELETE
MATRIX_ROW -> LIVING_RULE
PARKED_IDEA -> ACTIVE_WORK
RESEARCH_DOMAIN_DONE -> BUILD_DONE
NO_DROP -> CARRY_EVERYTHING_IN_CHAT
```

## DoesNotProve

## StopLine

Use as research routing support only. Stop before doctrine promotion, broad refactor, watcher, automation, graph database, current truth rewrite, active guide rewrite, or source deletion.
