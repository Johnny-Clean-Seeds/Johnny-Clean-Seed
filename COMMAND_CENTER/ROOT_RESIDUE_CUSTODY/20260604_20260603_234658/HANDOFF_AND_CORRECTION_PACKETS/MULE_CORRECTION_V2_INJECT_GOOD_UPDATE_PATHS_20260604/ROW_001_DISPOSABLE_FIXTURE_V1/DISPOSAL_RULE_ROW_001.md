# DISPOSAL RULE — ROW 001

## Purpose

Row 001 is disposable because it is a bench fixture, not authority.

The durable objects are the incident lesson, any approved rule, proof receipt, manifest, and later saved review result. The fixture itself should not become permanent doctrine by accident.

## Disposal is allowed only after

- The fixture path is identified.
- The learned lesson is captured or explicitly rejected.
- Any promoted item is named.
- Any parked item is named.
- The reviewer confirms no executable files were hidden inside the fixture.
- The reviewer confirms the target helper did not run as part of this fixture.
- The reviewer confirms durable proof files are not being deleted.

## Disposal actions

Allowed:

- Archive fixture as bench evidence.
- Delete fixture after lesson capture if the local lane allows cleanup.
- Keep fixture parked with a return trigger.

Blocked:

- Delete durable proof.
- Delete incident card.
- Delete rule file.
- Delete receipt or manifest.
- Promote fixture text into doctrine without a separate judge/save route.

## Disposal verdicts

`PARK_FIXTURE_ONLY`

`ARCHIVE_FIXTURE_AFTER_CAPTURE`

`DELETE_FIXTURE_AFTER_CAPTURE`

`PROMOTE_LESSON_NOT_FIXTURE`
