# Helper Thinking Logic Ladder Rule V0.1

Status: PUBLIC_NOTE / HELPER_THINKING_LOGIC / ACTIVE_LIMITED_SUPPORT / NOT_DOCTRINE
Date: 2026-06-13

Purpose:
Turn user thinking notes into safe stored thinking-pattern behavior for helpers. This does not make scripts conscious or autonomous. It gives helpers visible ways to know, choose, prove, compare, reflect, and propose under gates.

## Core Rule

Do not say files "think" as if they have private judgment.

Say helpers can use stored thinking patterns when their files carry:

- vocabulary;
- context;
- duty;
- input and output contracts;
- proof returns;
- if/then rules;
- decision tables;
- case examples;
- pattern names;
- reflection checks;
- promotion or parking rules.

## Safe Thinking Split

Use these visible layers:

1. `KNOWING`: retrieve facts, terms, paths, duties, and status.
2. `CHOOSING`: use a small rule or decision table.
3. `PROVING`: return proof, receipt, warnings, errors, and DoesNotProve.
4. `COMPARING`: match the current case to prior cases.
5. `REFLECTING`: compare expected versus actual and name mismatch.
6. `LEARNING`: propose a candidate update; do not install it by itself.

No helper should skip to learning before it can prove.

## Helper School Ladder

- Kindergarten: name and home.
- Grade 1: duty, input, output.
- Grade 2: proof-returning helper.
- Grade 3: refusal and if/then rules.
- Grade 4: small decision tables.
- Grade 5: case comparison.
- Grade 6: pattern family recognition.
- Grade 7: expected-versus-actual reflection.
- Grade 8: candidate maker.
- Grade 9: supervised reasoning under user/assistant review.

Immediate target: get useful helpers to Grade 2 and Grade 3 before building higher layers.

## Long String

Use this sequence when turning a loose idea, helper, note, or script into stored thinking-pattern behavior:

`DROP -> NAME -> SPECIES -> HOME -> VOCABULARY -> CONTEXT -> DUTY -> INPUT -> OUTPUT -> PROOF -> RULE -> DECISION -> CASE -> PATTERN -> TUNNEL -> TEST -> RETURN -> REFLECT -> PROMOTE/PARK/BLOCK`

Do not create a giant brain file. Add only the next missing layer that the helper can prove.

## Blocked Actions

- no hidden chain-of-thought capture;
- no doctrine promotion;
- no autonomous mutation;
- no cleanup, deletion, overwrite, Git/GitHub work, package install, or broad automation;
- no treating user notes, assistant analysis, or web pages as authority without proof.

## Does Not Prove

This rule does not prove a helper is intelligent, safe to mutate files, complete, or ready for automation. It only creates bounded visible thinking-pattern scaffolding helpers can use after proof gates.
