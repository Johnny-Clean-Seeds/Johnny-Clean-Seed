Date: 2026-05-31
Status: HARNESS SPEC / CANDIDATE SUPPORT / NOT DOCTRINE
WorkKey: CLAIM-CAPABILITY-BRIDGE-HARNESS-20260531-V1

## Purpose

Test whether small dangerous phrases are downgraded before they move the house.

This harness is intentionally small. It tests the first hinge between claim grammar and helper capability control.

## Bridge chain

```text
Input sentence
-> Claim force
-> Proof scope
-> Authority check
-> Capability needed
-> Capability state
-> Return contract
-> Receiver assay
-> Disposition
```

## Pass standard

The harness passes only if every fixture returns the expected bounded verdict.

Dangerous phrases must not inflate:

- helper pass into job pass
- hash custody into quality proof
- source ore into rule authority
- pattern trigger into command
- report existence into acceptance
- Git clean into whole-house clean
- ready into readiness without object/scope
- rule request into rule adoption

## Lower-worker rule

If the harness runner fails, do not judge the harness. Scratch the runner first:

1. parser
2. fixture read
3. row normalization
4. verdict calculation
5. coverage calculation
6. report writer

Only after the runner closes cleanly may the fixture verdict be trusted.
