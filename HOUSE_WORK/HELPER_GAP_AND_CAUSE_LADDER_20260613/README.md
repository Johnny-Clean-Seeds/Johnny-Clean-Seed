## Boundary

This workbench does not replace `CURRENT_TRUTH_INDEX.txt`, `ACTIVE_ANCHOR.txt`, active guides, user command, proof receipts, Chat Drop law, or helper-specific contracts.

It may create a packet or suggest a helper, but it cannot promote itself or authorize cleanup, Git, GitHub, deletion, overwrite, automation, or broad repair.

## Live Signals

- `HELPER_GAP_DETECTED`
- `HELPER_STALE_DETECTED`
- `HELPER_CAUSE_LADDER_CLEAR`

## Packet Folder

Use `PACKETS\` for real helper-gap records. Keep the template clean and copy its sections manually into a new packet when a specific gap needs evidence.

Do not create packets for every passing thought. Use packets for repeated pain, high-risk work, cross-surface sync, agent drift, missing/stale authority, tool errors, or recurring tasks.

## Does Not Prove

This workbench does not prove local Chat Drop state, public freshness, Git state, or helper correctness by itself. Use scanner output, receipts, hashes, and exact file paths.
