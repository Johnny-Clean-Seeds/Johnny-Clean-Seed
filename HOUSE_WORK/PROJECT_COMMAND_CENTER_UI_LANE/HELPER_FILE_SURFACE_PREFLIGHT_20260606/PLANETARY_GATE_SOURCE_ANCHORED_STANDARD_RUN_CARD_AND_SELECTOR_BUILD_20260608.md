   ROPE_ROUTER names the signal, reason, player/gate selected, counterweight needed, proof need, and stop condition. Rope selected does not authorize action.

08 Primary planet selection:
   Choose one primary planetary gate whose decision domain best matches the core issue. Do not fire every planet at full depth.

   Choose one counterweight planet that limits the primary planet's failure mode. The counterweight supplies balance, not a second full investigation.

10 Mechanical gate selection:
   Wake a mechanical gate only when a procedural proof or mechanism is needed. Mechanical gates include Code Gate, Proof Gate, Git Gate, Washer Gate, Path Guard, Hash/Receipt Gate, Fixture Gate, and Launch/Runtime Gate.

11 Earth check:
   Earth check names exact material proof and scope: path, file, folder, SHA256, root count, output report, receipt, command output, runtime launch result, artifact opening, or Git status only if a Git job is approved.

12 Final Judge route:
   Final Judge routes only within current mode, evidence, blockers, proof need, and DoesNotProve. It chooses ADOPT, ADAPT, PARK, BLOCK, PROOF, or LEAVE-BE.
