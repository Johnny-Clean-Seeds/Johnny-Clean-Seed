## 3. ACCESSION_RECORD GATE BINDING

No file counts as added to the house without an ACCESSION_RECORD.

Moving, copying, placing, or finding a file in a nicer folder is not accession.

An ACCESSION_RECORD must contain:

- original path
- current path
- SHA256 when practical
- object class
- parent/source relation
- move/copy/hold/leave decision
- authority basis
- proof or receipt path
- left-behind material when derivative
- DoesNotProve

If no ACCESSION_RECORD exists, the file remains:

NOT_ADDED_TO_HOUSE / ACCESSION_REQUIRED

If a file appears moved or copied without accession, classify:

SHUFFLE_WITHOUT_ACCESSION_REVIEW_REQUIRED

## 4. RAW CUSTODY GATE

Raw/source/input files are parent source.

Do not edit, delete, move, rename, overwrite, route, or treat raw/source/input files as trash unless explicitly authorized by the user.

Any derivative requires:

- raw parent path
- raw parent SHA256 when practical
- extracted material
- left-behind material
- reason
- DoesNotProve

## 5. ROOM/TOOL ROUTING GATE

No route is legal until Intake, SCENT/SMELL, Raw Custody, and ACCESSION_RECORD checks are satisfied or explicitly held with reason.
