## Core Correction

The Front Door / Intake Support Toolbelt is not optional decoration.

It is a protective guard membrane.

Every run performs:

1. Layer Echo first.
2. Light scan of all support organs.
3. Expansion only of triggered support organs.
4. Rope/player selection.
5. One primary planet.
6. One counterweight planet.
7. One Earth check.
8. Final route.

## Layer Echo First Rule

Layer Echo scans first because it protects the material from being chopped into separate problems when one repeated pattern is controlling multiple layers.

Layer Echo checks:

WORD_LAYER
PATH_LAYER
PROOF_LAYER
ACTION_LAYER
ROOM_LAYER
GATE_LAYER
TIME_LAYER
USER_INTENT_LAYER
ASSISTANT_BEHAVIOR_LAYER

Rule:

ECHO_BEFORE_TOOLBELT_EXPANSION

No support organ should start cutting, washing, invoking, routing, promoting, or blocking deeply until Echo checks whether the same pattern is repeating across layers.

## Expansion Rule

If a support guard does not trigger, it stays light.

If it triggers, expand only that support organ.
