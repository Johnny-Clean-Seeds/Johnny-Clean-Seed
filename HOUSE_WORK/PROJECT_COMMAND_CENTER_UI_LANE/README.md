## Purpose

This lane defines the user-facing Project Command Center UI surface and the proof boundaries around it.

It does not replace the existing `COMMAND_CENTER` tree. It stands in front of it as a findable design, command, path, and proof lane.

## Lane Decision

Reason: the existing `COMMAND_CENTER` tree contains useful command-center history and operational surfaces, including scripts, watcher-adjacent material, and remote-door material. The UI lane needs a clean design/proof home before any operational bridge is activated.

## Boundary

No target/helper execution. No watcher. No automation. No package install. No live UI implementation. No doctrine promotion. No ACTIVE_GUIDES edit. No CURRENT_TRUTH_INDEX edit.
