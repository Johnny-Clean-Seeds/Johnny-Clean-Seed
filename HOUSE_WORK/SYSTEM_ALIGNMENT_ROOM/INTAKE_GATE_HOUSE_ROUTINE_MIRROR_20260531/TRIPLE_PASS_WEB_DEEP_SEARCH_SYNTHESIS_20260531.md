## Fit Findings

### 1. Provenance strengthens custody.

Local fit:

The house already has source custody, hash, receipt, and helper assay language. W3C PROV gives a clean external shape for the same need:

`entity -> activity -> agent -> derivation -> association`

Adopt as candidate support:

`CUSTOMS MARK V3` can use entity/activity/agent fields when helper or report movement is unclear.

### 2. Zero trust strengthens inversion.

Local fit:

The house already says no trust by location and no raw source becomes executable. NIST zero-trust framing strengthens the rule that a saved object is not automatically allowed to act.

Adopt as candidate support:

Receiver assay should ask:

`Identity verified? Authority verified? Lane verified? Proof verified? Return verified? Current use allowed?`

### 3. WIP limit strengthens carry discipline.

Local fit:

The routine already says one active object, one helper output, one proof report, one next action. Kanban strengthens this as an explicit flow policy instead of preference.

Adopt as candidate support:

If the routine has more than one active object or more than one proof surface, park overflow with rope note and return trigger.

### 4. Systems relation strengthens walls walk.

Local fit:

NASA systems engineering emphasizes that system value comes from relationships among parts. That matches the house rule that a file can be locally clean but still steal a neighbor's job.

Adopt as candidate support:

Walls pass must name neighbor fit before calling a patch clean.

### 5. Cognitive load strengthens "carry key, not furniture."

Local fit:

The house already suffers when old proof, helper output, and root material stay live. Cognitive-load theory gives the reason: working memory is constrained, and unnecessary load degrades transfer.

Adopt as candidate support:

Every routine pass must say what chat no longer needs to remember and where that memory was placed.

### 6. OODA strengthens triple pass.

Local fit:

The user asked for walls, upside-down, then deep search. OODA maps cleanly:

- walls = observe and orient on current house
- upside-down = wargame friction and orientation failure
- web deep search = re-orient with outside method keys
- final patch/receipt = decide and act
- re-audit = new observation

Adopt as candidate support:

Reset orientation between pass waves. Do not let the previous branch smear into the next pass.

### 7. Event sourcing strengthens receipts.

Local fit:

The house already uses proof receipts. Event sourcing strengthens the idea that state-changing movement should be reconstructable from events.

Adopt as candidate support:

Each routine pass should leave a receipt/event row with prior state, action, result, proof pointer, and next condition.
