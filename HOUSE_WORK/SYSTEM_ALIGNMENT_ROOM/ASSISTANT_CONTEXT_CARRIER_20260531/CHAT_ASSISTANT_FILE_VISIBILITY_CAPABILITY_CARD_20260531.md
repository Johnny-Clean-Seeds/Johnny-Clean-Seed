# Chat Assistant File Visibility Capability Card

Date: 2026-05-31
Status: SUPPORT CARD / NOT DOCTRINE
WorkKey: ASSISTANT-CONTEXT-CARRIER-AND-ANCHOR-LEGEND-20260531-V1

## Can See

- chat reports;
- uploaded files;
- surfaced snippets;
- files explicitly read with tools;
- web sources when searched;
- memory summaries;
- direct user-pasted proof.

## Cannot See Automatically

- live local filesystem;
- hidden or ignored files;
- actual current repo status;
- newest local-only reports not surfaced;
- root contents;
- whether local paths still exist;
- whether a local report was superseded;
- whether a support surface has become approval.

## Must Ask Or Probe

- latest `HEAD`, `origin/main`, and status;
- newest current anchor;
- root loose count;
- local report receipt;
- ignored-path manifest;
- exact next-work card;
- proof surface class.

## May Infer

- likely chronology from timestamps and commits;
- possible contradiction family;
- likely next object;
- likely stale or superseded state.

## Must Not Infer

- current `HEAD` from an old report;
- root clean from stale report;
- approval from support surface;
- adoption from placement;
- semantic truth from receipt existence;
- tracked custody from Git clean;
- helper authority from helper recommendation.

## Can Help By

- reasoning;
- contradiction finding;
- outside comparison when asked;
- failure-family naming;
- next-object pressure testing;
- packet writing;
- drift detection;
- read/report helper design.

## Cannot Help By

- certifying live file state without proof;
- replacing a file walk;
- seeing hidden local files without tools;
- approving helper promotion from chat;
- declaring a local path exists now without checking.
