## Purpose

Give outside/chat helpers a compact, file-grounded way to re-anchor without loading the whole house or trusting chat memory as house truth.

The carrier rule is simple:

`maximum reach, minimum carry`

Helpers should get the files they need to know for the active object. Sometimes that is a whole target script. Often it is only a path, hash, receipt, ledger row, source map, or small line window.
