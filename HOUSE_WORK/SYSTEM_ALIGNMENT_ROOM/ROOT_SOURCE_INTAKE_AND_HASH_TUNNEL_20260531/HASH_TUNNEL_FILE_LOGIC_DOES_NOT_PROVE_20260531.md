# Hash-Tunnel File Logic Does Not Prove

Status: SUPPORT LIMIT NOTE / NOT DOCTRINE

A hash does not prove:

- meaning;
- quality;
- approval;
- current authority;
- clean placement;
- safe execution;
- doctrine adoption;
- user intent beyond the exact source;
- file freshness after the hash was taken.

A tunnel does not prove:

- action is authorized;
- the route is complete;
- the target should be changed;
- the source object is correct;
- the receiving room accepted the object.

A receipt does not prove:

- semantic correctness;
- final approval;
- future freshness;
- that ignored or local-only files are handled;
- that source concepts were applied.

A support room does not prove:

- active-guide doctrine;
- `CURRENT_TRUTH_INDEX.txt` truth;
- helper authority;
- permission to delete or move root files.

Clean use:

`hash -> identity`

`tunnel -> relation and route`

`receipt -> event/custody proof`

`receiver assay -> judgment`

`explicit user/house authority -> permission`
