# Helper Shape Self-Test Bench Live-Use Suit Card

Date: 20260531  
Status: CHAT COCKPIT SUPPORT CANDIDATE / NOT DOCTRINE  

## Wear line

Project first. Test tool shape before tool writes.

## Use when

Use when a generated helper/save script will write markdown, reports, receipts, manifests, or generated line content.

## Checks

- Does the active project object remain named?
- Is the tool only a delivery layer?
- Does the self-test run in local safe output space?
- Does it cover blank lines and empty expected strings?
- Does it cover arrays and scalar strings?
- Does it cover Markdown punctuation and backticks?
- Does the save branch stay blocked unless the self-test passes?

## Do not

Do not promote this to doctrine from one proof.
Do not turn PowerShell into the project object.
Do not skip project proof because the tool passed.

## Boundary

Support candidate only. No doctrine, ACTIVE_GUIDES, CURRENT_TRUTH_INDEX, automation, watcher, broad framework, move, removal, reset, stash, or checkout.
