# Console Severity Color Suit Card

Saved: 20260603_140117

## Wear now

CONSOLE_SEVERITY_COLOR_RULE

## Apply when

A script prints warning counts, warning explanations, pass/fail status, final proof, next legal action, paths, or hashes.

## Required behavior

1. Keep plain text complete.
2. Add color by severity.
3. Make warning blocks visually scannable.
4. Do not let color replace proof.
5. Treat color as operator visibility, not authority.
6. Keep color-only updates separate from logic changes unless authorized.

## StopLine

If a script's warning content is correct but visually flat, route a color-only console UX update. Do not alter behavior accidentally.
